# 游戏 WebView 宽高比设计

## 目标

在手机竖屏上按展示模式设置 WebView 尺寸：半屏宽高比为 `1:1`，大半屏宽高比为 `1:1.5`，全屏继续占满安全区。

## 方案

- WebView 保持页面全宽并贴在安全区底部。
- 半屏使用 `高度 = 宽度 × 1.0`。
- 大半屏使用 `高度 = 宽度 × 1.5`。
- 全屏不使用宽高比，继续使用安全区完整高度。
- 模式层提供可测试的“高度/宽度比例”；全屏返回 `nil`。
- 不修改背景图、游戏 URL、`gameId` 或 `mini` 映射。
- 本次只考虑项目已配置的 iPhone 竖屏，不增加 iPad 横屏适配。

## 验证

- 聚焦测试验证半屏、大半屏和全屏的尺寸配置。
- 无签名构建验证 Auto Layout 代码能够编译。
- 运行时仍需在手机模拟器或设备上确认实际渲染尺寸。
