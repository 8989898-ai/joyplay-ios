# 游戏模式 Tab 图标设计

三个 Tab 保留现有的“全屏”“半屏”“大半屏”标题与交互，只补充一套统一的单色模板图标。每个图标使用相同的横向圆角屏幕轮廓，通过内部自底向上的填充比例表达游戏画面的占屏范围：全屏为 100%，半屏为 50%，大半屏为 70%。这种表达比近似的 SF Symbols 更准确，也避免小尺寸数字图标的辨识问题。

图标由 UIKit 在运行时绘制为模板图片，沿用 Tab Bar 的系统选中与未选中颜色，不引入额外图片资源。比例属于 `GameDisplayMode` 的展示规则，可由聚焦测试验证；绘制代码仅负责把该比例转成图形。验证包括比例规则测试、无签名模拟器构建和运行时视觉检查，视觉检查重点确认三种填充差异、选中态着色与小尺寸清晰度。
