# 打开游戏按钮轻柔呼吸效果设计

## 目标

让全屏、半屏和大半屏三个模式共用的“打开游戏”按钮持续进行轻柔缩放，吸引点击，同时保持按钮可交互。

## 设计

- 在 `GameModeLaunchViewController` 内统一管理 `gameButton` 动画，一次覆盖三个游戏模式。
- 使用 UIKit `UIView.animate`，先缩小至 `0.96`，再用 `0.6` 秒动画放大至 `1.04`，通过自动反向形成约 `1.2` 秒的完整呼吸周期。
- 动画采用 `curveEaseInOut`、`autoreverse`、`repeat` 和 `allowUserInteraction`。
- 页面出现时启动；打开游戏或页面离开时停止并恢复原尺寸；嵌入游戏关闭、按钮重新显示时再次启动。
- 当系统开启“减弱动态效果”时保持按钮原尺寸，不播放动画。

## 验证

- 扩展现有按钮源码测试，覆盖缩放范围、周期、循环交互选项、辅助功能判断及生命周期启停。
- 运行按钮专项测试、全部 Swift 脚本测试和无签名模拟器编译。
