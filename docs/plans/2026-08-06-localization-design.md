# 英文与简体中文本地化设计

## 目标

将 App 内所有用户可见的本地文案适配为英文和简体中文，跟随 iOS 系统语言显示；系统语言不受支持时回退英文。

## 范围

- 本地化首页标题、分组标题、输入框占位文案和按钮标题。
- 本地化游戏模式标题、游戏页标题、按钮标题和返回按钮无障碍标签。
- 不处理控制台日志、URL、查询参数、资源名称、系统图标名称、JS 回调名及其他协议或技术常量。
- 不改动布局、导航、校验、网络请求或游戏交互逻辑。

## 方案

新增一个 `Localizable.xcstrings` 字符串目录，以英文为源语言，维护 `en` 和 `zh-Hans` 两套值。Swift 代码使用语义化 key 读取本地化字符串，并为每个 key 提供英文默认值。工程现有 `developmentRegion = en` 保持不变，因此其他系统语言会回退英文。

采用单一字符串目录而非两套 `.strings` 文件，减少重复 key 的维护成本；不在代码中手动判断系统语言，以保留 iOS 原生的语言匹配与回退行为。

## 验证

1. 先增加资源测试，验证英文和简体中文 key 完整、值符合预期以及默认开发语言为英文，并确认测试在资源缺失时失败。
2. 新增字符串目录并替换用户可见硬编码文案后，重新运行测试确认通过。
3. 扫描 Swift 文件，确认剩余中文只存在于明确排除的控制台日志中。
4. 执行无签名 iOS 模拟器构建，确认资源被打包且代码可编译。
