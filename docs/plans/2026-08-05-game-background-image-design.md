# 游戏页背景图片设计

## 目标

游戏页面使用 `voice-chat-bg2.jpg` 作为全区域背景。图片保持原始宽高比，覆盖页面且不发生拉伸；超出页面比例的部分居中裁切。

## 设计

- 将图片加入 `Assets.xcassets`，由应用资源目录统一管理。
- 在 `GameViewController` 的根视图中添加背景 `UIImageView`，约束到根视图四边。
- 背景图使用 `scaleAspectFill`，并裁切超出边界的内容。
- 背景层位于现有 `WKWebView` 下方，不改变 WebView 的高度比例和底部对齐逻辑。

## 验证

- 检查资源和代码差异，确认只增加游戏页背景。
- 执行无签名 Xcode 构建，确认资源和代码均可编译。
- 运行时检查半屏、大半屏模式的上方区域；图片应铺满且比例正常。全屏模式下背景位于 WebView 后方。
